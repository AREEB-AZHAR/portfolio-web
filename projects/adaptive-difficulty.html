01 // THE STARTING POINT

The player's psychological flow state is delicate.
Rubber-banding ruins it.

Traditional game difficulty balancing relies on primitive rubber-banding: artificially buffing enemy health when the player is winning, or reducing puzzle steps when they fail repeatedly. Players immediately detect this manipulation, shattering their immersion and sense of accomplishment.

The goal of this research was to construct an invisible, non-intrusive neural inference engine that continuously predicts player cognitive load and skill delta, smoothly tuning mechanics without overt cues.

02 // ARCHITECTURE IN PRACTICE

Sub-16ms telemetry processing inside the game loop.

REAL-TIME INFERENCE PIPELINE // ADAPTIVE DIFFICULTY ENGINE
  • 01 / Telemetry Collector
  • 02 / Barracuda ONNX Runner
  • 03 / Procedural Difficulty
STEP 01

Non-Intrusive Telemetry Vector

A high-frequency C# telemetry service buffers player input timings, time spent evaluating board positions, and backtracked moves into a rolling 30-second feature vector without triggering garbage-collection spikes.

STEP 02

Zero-Allocation Neural Inference

Trained on offline synthetic gameplay patterns in PyTorch, the network is exported to ONNX format and executed on CPU/GPU worker threads via Unity's Barracuda engine, completing forward inference in an average of 2.1 milliseconds.

STEP 03

Dynamic Procedural Recalibration

The output skill metric smoothly adjusts environmental entropy parameters: puzzle branch depth, distractor nodes, and time windows. Players consistently report feeling challenged without ever experiencing boredom or rage-quit frustration.
